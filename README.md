Nome do projeto: 
Hydrates

Resumo:
O Hydrates é um sistema de acompanhamento de hidratação desenvolvida 
com o objetivo de auxiliar os usuários a manterem um controle simples e organizado do consumo diário de água. 
A proposta do projeto é oferecer uma ferramenta prática, intuitiva e de fácil utilização, 
permitindo que o usuário acompanhe sua ingestão de água ao longo do dia e tenha uma supervisão do seu progresso em relação à meta estabelecida.

Funcionalidades:

* Cadastro do usuário.
* Cálculo de uma meta diária de água.
* Registro do consumo de água.
* Barra de progresso da meta diária.
* Histórico de consumo.
* Lembretes para beber água.
* Configurações do usuário.
* Armazenamento dos dados localmente.
